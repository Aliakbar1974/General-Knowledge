# General-Knowledge

World General Knowledge MCQ quiz collection, including History, Geography, ICT, Space, Science, Literature, Economics, Politics, Sports, and related topics.

## Keep quizzes in this repository

Use one folder per quiz and include a direct `index.html` in that folder. Continue the numbering for each subject without overwriting an existing quiz.

Examples of the existing naming style:

```text
History-Quiz-01/
History-Quiz-02/
...
History-Quiz-05/
Geography-quiz-06/
Geography-quiz-07/
Geography-quiz-08/
```

For future quizzes, preserve a consistent subject-plus-number pattern, such as `History-Quiz-06/`, `Geography-Quiz-09/`, or `Space-Quiz-01/`. The folder must contain `index.html`; keep quiz-specific `script.js`, `style.css`, `Images/`, and `Sounds/` alongside it when used.

## Publishing and website listing

- GitHub Pages: https://aliakbar1974.github.io/General-Knowledge/
- Website library: https://quizchallengebd.com/general-knowledge-quizzes.html

The website library discovers quiz folders in this repository. After adding a new quiz, verify its folder and page URL, then check the General Knowledge library page.

## Quality checklist

- Validate facts and explanations; use reliable sources for changing or specialised facts.
- Confirm the answer index matches the correct option after shuffling.
- Balance answer positions according to the quiz brief.
- Check mobile layout, assets, timer, modes, and completion screen.
- Do not place Bangladesh Studies, Vocabulary, or English Grammar quiz folders here.
